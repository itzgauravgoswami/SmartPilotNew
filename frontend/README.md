# Smart Pilot — Frontend Client

The frontend client of Smart Pilot is a single-page application built with React 19, Vite, and Tailwind CSS. It delivers an interface for business analytics, invoice generation, customer management, AI interactions, team collaboration, and subscription management.

## Technology Stack

- Framework: React 19
- Build Tool: Vite 8
- Routing: React Router v7
- Styling: Tailwind CSS v4
- Icons: Lucide React
- Document Export: html2pdf.js, html2canvas-pro
- Code Quality: ESLint 10

## Available Scripts

In the `frontend` directory, the following scripts can be executed:

### `npm run dev`
Launches the Vite development server with Hot Module Replacement (HMR) enabled:
```bash
npm run dev
```
Default local address: `http://localhost:5173`

### `npm run build`
Compiles and bundles the application for production into the `dist` directory:
```bash
npm run build
```

### `npm run preview`
Locally serves the production bundle generated by `npm run build`:
```bash
npm run preview
```

### `npm run lint`
Runs ESLint across JavaScript and JSX files to identify code quality issues:
```bash
npm run lint
```

## Environment Variables

Create a `.env` file in the `frontend` directory based on `.env.example`:

```env
VITE_APP_URL=http://localhost:5173
VITE_API_URL=http://localhost:5000

VITE_GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com
VITE_GITHUB_CLIENT_ID=your_github_client_id
VITE_MICROSOFT_CLIENT_ID=your_azure_app_client_id
```

| Variable | Description |
| :--- | :--- |
| `VITE_APP_URL` | Base origin URL of the running frontend application. |
| `VITE_API_URL` | Base origin URL of the backend API service. |
| `VITE_GOOGLE_CLIENT_ID` | OAuth 2.0 client ID for Google authentication. |
| `VITE_GITHUB_CLIENT_ID` | Client ID for GitHub OAuth authentication. |
| `VITE_MICROSOFT_CLIENT_ID` | Application client ID for Microsoft Azure OAuth. |

## Key Features and Workflows

- Real-Time Business Dashboard: Summarizes total sales, outstanding invoices, pending tasks, and month-over-month growth analytics.
- Invoice Maker: Live invoice composition with discount, tax, item lines, payment terms, and direct PDF generation using html2pdf.js.
- Company Profile Configuration: Setup business credentials, GST details, bank coordinates, and digital signatures for automatic invoice embedding.
- AI Copilot Drawer: Interactive business assistant powered by Gemini 2.5 Flash, providing contextual data insights.
- Team Connect: Channel and direct message communication workspace available for Premium subscribers.
- Device Limit Detection: Automatic modal prompting users when concurrent device quotas are reached, enabling selective remote device eviction.

## Production Deployment

The frontend includes a `vercel.json` configuration for client-side single page routing rewrites:

```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

Ensure production environment variables (`VITE_API_URL`, OAuth client IDs) are configured in the Vercel project settings prior to deployment.
